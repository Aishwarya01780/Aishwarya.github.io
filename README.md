# Personal Portfolio Website

## 📌 Project Description

This is a simple personal portfolio website created using HTML. It introduces me, displays my educational background, interests, and technical skills.

## 💻 Technologies Used

- HTML5 – Used to create the structure of the webpage.

## 📖 Code Explanation

### 1. HTML Document Structure

```html
<!DOCTYPE html>
<html>
```

- `<!DOCTYPE html>` declares that the document uses HTML5.
- `<html>` is the root element of the webpage.

### 2. Head Section

```html
<head>
    <title>Aishwarya | Portfolio</title>
</head>
```

- `<head>` contains information about the webpage.
- `<title>` sets the title displayed on the browser tab.

### 3. Body Section

```html
<body>
```

- `<body>` contains all the visible content displayed on the webpage.

### 4. Introduction Section

```html
<h1>Hi, I'm Aishwarya!</h1>
<h2>CSE (AI & ML) Student</h2>

<p>Welcome to my personal portfolio.</p>
```

- `<h1>` displays the main heading.
- `<h2>` displays the subheading.
- `<p>` displays a paragraph introducing the portfolio.

### 5. About Me Section

```html
<h2>About Me</h2>

<p>I am interested in Artificial Intelligence,
Machine Learning and Web Development.</p>
```

- Displays the About Me heading.
- The paragraph describes my interests in technology.

### 6. My Skills Section

```html
<h2>My Skills</h2>

<p>C | C++ | Python | HTML | CSS</p>
```

- Displays the skills heading.
- Lists my programming languages and web development skills.

### 7. Closing Body and HTML Tags

```html
</body>
</html>
```

- `</body>` closes the body section.
- `</html>` marks the end of the HTML document.

## 🎯 Project Objective

The objective of this project is to create a basic personal portfolio website and understand the fundamentals of HTML, including headings, paragraphs, document structure, and webpage content.

## 🚀 Output

The webpage displays:
- Personal introduction
- Educational background
- About Me section
- Technical skills

## 📚 Learning Outcomes

Through this project, I learned:

- Usage of HTML heading tags.
- Creating paragraphs using `<p>`.
- Understanding opening and closing HTML tags.
- Creating a simple personal portfolio webpage.
